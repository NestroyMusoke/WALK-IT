# VS Code setup for the next WALK IT agent

This file describes the **official Anthropic Claude Code VS Code extension**. Its publisher is Anthropic and its Marketplace listing is https://marketplace.visualstudio.com/items?itemName=Anthropic.claude-code . Official instructions: https://code.claude.com/docs/en/vs-code . The video described a separate “Ultra” promotion and a model list including non-Anthropic models; its platform URL was not provided, so the offer, billing and compatibility with Anthropic's extension are **unverified**. A third-party Ultra plan may require that platform's own extension or account; it is not evidence of an Anthropic Pro/Max subscription.

1. In VS Code, choose **File → Open Folder** and open `C:\Users\X1 Yoga\Documents\Codex\WALK-IT` (the repository root, not `apps\web` or the older pasted-files folder).
2. Press **Ctrl+Shift+X**, search **Claude Code**, verify publisher **Anthropic**, and install. Or open the Marketplace link above. The official docs say VS Code 1.94+ and an Anthropic paid subscription or Console account are prerequisites; no API key is needed for subscription sign-in.
3. Open any repository file. Click the Spark icon in the editor toolbar or Activity Bar, or run **Claude Code: Open in New Tab** from **Ctrl+Shift+P**. Click **Sign in** and finish in the browser. If the account is an actual Anthropic Pro/Max subscription, sign in with that account. If the six-month Ultra account is on another website, first identify its publisher and supported VS Code integration; it may not authenticate in the official extension.
4. In Claude Code, use `/status` to inspect which account and usage source is active. For subscription usage, keep `ANTHROPIC_API_KEY` unset: Anthropic says an environment API key takes precedence and can incur API charges. Decline prompts to switch to paid API credits if the intent is no extra spend. An Anthropic subscription is not unlimited, and subscription limits differ from API credits.
5. Open `CLAUDE.md`; the extension loads it as project guidance. In the first chat paste: **“Read `AGENTS.md`, `docs/AGENT_HANDOFF.md`, `PLAN.md` and `TASKS.md`. Inspect `git status` and the staged E06b changes. Continue the next safe card with a failing acceptance test first. Update the handoff after the card. Give me exact Windows Git commit and push commands; do not commit for me.”**

If a third-party “Ultra” tool is used instead, check its actual provider domain, extension publisher, permissions, usage limits and billing before connecting GitHub, entering an API key, or granting access to private recordings. Open this same local repository and paste the same first-chat instruction. Keep `.env`, credentials and `eval/sessions` out of Git. Do not upload private images to any model or service without the user's explicit route/participant permission and review.
